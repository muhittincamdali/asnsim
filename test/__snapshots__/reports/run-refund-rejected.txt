       rejected: The webhook answered 500: the App Store would count the delivery as failed.
       How to fix:
       - The App Store counts HTTP 200 to 206 as success and every other status as a failed
         delivery. In production the App Store retries a failed notification five times, 1, 12, 24,
         48 and 72 hours after the previous attempt; in the sandbox it sends it once.
       - If the endpoint rejects payloads it cannot verify, configure its tests to trust
         .asnsim/root.cer with online checks off, and the bundle ID and environment in
         .asnsim/asnsim.json.
       - Return 200 for notification types the server does not handle, so the App Store does not
         retry them.
